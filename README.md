# Social Network Ads Purchase Prediction

## 1. Project Overview
This project focuses on predicting whether a user will purchase a product after viewing an advertisement on a social network. It uses Logistic Regression, a supervised Machine Learning classification algorithm.

## 2. Project Objective
The main objective is to build a classification model that learns from user data and predicts the purchase outcome.
